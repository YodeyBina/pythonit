# פייתונית – פייתון בעברית

סביבת עבודה דו־לשונית ללימוד פייתון: כותבים קוד בפייתון ורואים לידו תרגום מקביל לעברית, ולהפך.

## האתר

**[לחצו כאן לפתיחת האתר](https://yodeybina.github.io/pythonit/)**

## הרצת קוד

הדפדפן אינו יכול להריץ פייתון, ולכן באתר אפשר לכתוב ולתרגם קוד בלבד.
לחיצה על "הרץ" מציעה להוריד את התוכנה להרצה במחשב שלכם.

1. מורידים את [pythonit-desktop.zip](pythonit-desktop.zip) ומחלצים אותו.
2. מתקינים פייתון 3.8 ומעלה מ־python.org, אם עדיין אין.
3. מריצים את הקובץ `pythonit.py`. ב־Windows אפשר ללחוץ פעמיים על `start.bat`.
