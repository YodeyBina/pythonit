# פייתונית – פייתון בעברית

סביבת Python דו־לשונית: כותבים קוד בפייתון ורואים תרגום מקביל לעברית (ולהפך).

**האתר:** כתובת ה-GitHub Pages של הפרויקט (ראו הוראות בהמשך).

באתר אפשר לכתוב ולתרגם קוד. הדפדפן אינו יכול להריץ Python, ולכן לחיצה על "הרץ" מציעה להוריד את התוכנה להרצה מקומית (`pythonit-desktop.zip`): חלצו, והריצו `pythonit.py` (ב-Windows: `start.bat`). נדרש Python 3.8 ומעלה.
